# Ruins Enhanced 구면 맵

현재 맵: Project/assets/model/map/future_ruins_planet_separated.glb

2026-10-11 사용자가 지정한 Expedition_Ruins_Enhanced/future_ruins_planet_separated.glb를 그대로 복사했습니다. Client와 Server의 에셋 복사 대상과 Shared의 맵 경로가 이 파일을 사용합니다. 기존 ResourceManager → Model → LegacyScene → GRenderer 구조와 공통 PlanetSurface → TerrainSampler 접지 경로를 유지합니다. Assimp나 FBX SDK가 필요하지 않습니다.

## 좌표와 시작 위치

원본은 미터 단위, 중심 (0,0,0), 기준 반경 650m의 닫힌 구면입니다. 실제 지형 정점 반경은 약 631.59~700.97m입니다. Shared::GlbDocument는 Z와 삼각형 순서, 노드 변환을 함께 DirectX 좌수계로 바꿉니다. 원본 노드의 회전·배율·이동을 한 번 적용하고 추가 전체 배율은 1입니다.

Shared::kUsePlanarMap=false, kPlanetRadius와 kPlanetModelReferenceRadius는 모두 650입니다. 월드 중심은 (0,-650,0)이며 렌더·플레이어·카메라·NPC·서버 위치 보정과 사격 지형 판정이 같은 상수를 사용합니다. 위쪽은 중심에서 현재 위치로 향하는 방향, 고도는 기준구 위의 거리입니다.

시작 위치는 Landing L1의 좌수계 단위 방향 (-0.3261576291,0.9179231599,-0.2259165190)입니다. 클라이언트와 서버는 해당 방향의 실제 플랫폼 높이에 몸통-발 오프셋 1m를 더합니다. 원시 GLB의 L1 방향 방사 교차 계산에서 지형 반경은 약 653m, 플랫폼은 653.0201m이며 몸통 중심 반경은 654.0201m입니다. 이 수치는 게임 실행 측정이 아닙니다.

원격 플레이어와 NPC도 받은 좌표는 그대로 사용하고 행성의 위쪽 방향에 캐릭터 자세를 정렬합니다. 통신 패킷에 방향이 없으므로 정면은 해당 지점의 접평면 기준으로 구성합니다.

## 지면 선택

PlanetSurface가 다음 노드의 위치·삼각형만 읽어 BVH를 만듭니다.

- COL_Expedition_Planet_Terrain: 표시 지형 Terrain_Expedition_Planet_Closed와 같은 메시
- Landing_L*_Platform: 표시용 착륙 플랫폼 4개

새 자산은 도로를 지형의 색상 텍스처에 통합해 별도의 Walkable_Path_* 메시가 없습니다. 기존 접지 선택은 해당 노드가 있을 때만 읽으므로 도로용 중복 삼각형을 만들지 않습니다.

각 노드의 실제 월드 변환을 적용한 자산 좌표를 저장하고 방사 방향에서 가장 바깥 접지면을 찾습니다. 구면의 옆면도 지면이므로 퇴화 판정은 X/Z 투영 대신 3D 삼각형 면적으로 계산합니다. OBJ와 GLB 위치는 모두 좌수계로 보관해 높이 조회에서 Z를 다시 반전하지 않습니다.

일부 COL_Landing_* 프록시는 원본의 부모·자식 변환이 상쇄되어 중심 근처에 배치됩니다. 이 프록시 대신 실제 플랫폼을 사용합니다. 건물 벽·지붕·엄폐물은 높이 조회에 포함하지 않으며 체적 충돌은 기존 시스템의 별도 과제입니다.

## 로딩과 렌더 최적화

- GlbDocument::ReadGeometry는 접지용 위치와 인덱스만 디코딩합니다. 렌더 정점의 법선·UV·색상·접선 복사를 생략해 임시 정점 크기를 64→12바이트로 줄입니다.
- 검증된 geometry 개수를 먼저 합산해 접지 배열을 한 번 예약합니다. 임시 GLB/geometry는 BVH를 만들기 전에 해제하고 BVH 노드도 필요한 개수만 예약합니다. 높이 조회는 고정 크기 스택을 사용합니다.
- 반복 나무·건물은 고유 mesh/primitive의 CPU·GPU 데이터를 공유하고 각 노드에는 변환만 둡니다.
- 고유 메시를 옮길 때 로컬 AABB를 한 번 계산하고 노드 경계는 8개 모서리만 변환합니다. 이 자산의 전체 노드 경계 계산은 5,439,392개 정점 변환에서 12,640개 모서리 변환으로 줄어듭니다.
- LegacyScene은 기존 SoA/API를 유지하며 변경된 로컬 변환·가시성과 부모 변경만 자식에게 전달합니다. 초기화 뒤 정적 맵의 행렬을 매 프레임 다시 곱하지 않습니다.
- 충돌 프록시·크기 안내·제작 가이드와 라벨 메시 23개는 표시에서 제외합니다. 해당 노드는 변환 계층을 유지합니다.
- 모든 면이 바깥 방향인 닫힌 지표면만 뒷면 제거를 적용합니다. 건물과 나무의 원본 양면 설정, 지형의 정점 색상은 유지합니다.
- 기존 프러스텀 제거와 연속 GPU 바인딩 생략을 유지합니다. GPU 업로드 뒤 CPU 모델은 ReleaseModel로, 임시 UPLOAD 버퍼는 펜스 완료 뒤 해제합니다.

현재 파일에는 지형·도로 색상(4096×2048), 콘크리트와 부식 금속 색상(각 1024×1024)의 내장 PNG 3장이 있습니다. 기존 WIC 메모리 디코딩으로 각 이미지를 한 번 읽고 해당 재질들이 같은 GPU 텍스처를 공유합니다. 외부 텍스처 파일은 추가로 복사하지 않습니다. 스킨·애니메이션은 없으며 기본 PBR 재질과 정점 색상을 유지합니다. clearcoat/transmission/ior/sheen은 기존 셰이더의 기본 PBR 표현으로 표시합니다. 사용하지 않는 TEXCOORD_1은 개수·형식을 검증하고 읽기를 생략합니다. 지원하는 내장 색상·발광 텍스처는 UV0 규약을 유지합니다.

## 메모리와 성능 확인

다음은 원본 데이터와 자료구조 크기의 정적 계산입니다. 프로세스 메모리나 FPS 실측이 아닙니다.

| 데이터 | 크기 |
|---|---:|
| 새 GLB 파일 | 약 57.56 MiB |
| 제작 가이드 제외 후 공유 렌더 정점·인덱스 | 약 86.64 MiB |
| 내장 텍스처 RGBA8 픽셀 합계 | 40.00 MiB |
| 지면·플랫폼 위치/삼각형/BVH | 약 21.45 MiB |
| 교체 직전 프로젝트 맵의 공유 렌더 정점·인덱스 | 약 118.37 MiB |

렌더 노드는 509개, 고유 메시 147개, 고유 primitive 410개, 컬링 전 draw 인스턴스는 1,580개입니다. 공유 렌더 데이터는 1,243,648정점/1,352,448삼각형이며 정점당 60바이트인 swc::Vertex의 필드 크기로 계산했습니다. 접지 입력은 335,687정점/664,592삼각형입니다. 반복 노드를 메시 데이터로 펼치지 않습니다.

교체 직전 프로젝트 파일은 71,818,636바이트이며 같은 3장의 텍스처가 포함되어 있었습니다. 지정된 새 파일로 교체하면서 공유 렌더 geometry는 약 31.73MiB 감소하고 컬링 전 제출 후보 삼각형은 6,828,828개에서 6,245,052개로 줄었습니다. 이 비교는 원시 에셋과 소스 구조의 계산이며 FPS 향상률이 아닙니다.

공유 렌더 geometry와 디코딩한 텍스처 합계는 약 126.64MiB입니다. 접지 데이터, 드라이버·GPU 버퍼·업로드 사본, 캐릭터·하늘 행성 등은 별도이므로 전체 프로세스 메모리로 해석하지 않습니다. 이 파일에는 플레이 가능한 맵의 LOD가 없으며 기존 시야 제거를 유지합니다.

Visual Studio 출력창의 [Memory]는 before map load / ground loaded / map parsed / map GPU uploaded / map CPU released / sky planet CPU released / character CPU released와 30초마다 runtime의 private·workingSet·peakWorkingSet·cpuModel·cachedModels를 출력합니다. CPU 모델 해제 뒤 cachedModels는 0이며 peakWorkingSet은 이전 최대값이라 해제해도 내려가지 않습니다.

창 제목의 FPS, Draw, Cull, Tri는 실제 실행 시 확인할 수 있습니다. Tri는 GPU에 제출한 삼각형 수이며 뒷면·깊이 판정 뒤 화면에 남은 수가 아닙니다. 빌드·실행은 사용자 요청에 따라 수행하지 않았습니다.

## 하늘 행성

SkyPlanet의 기존 FPS_LOD_Optimized LOD2·LOD3 GLB는 별도 원거리 배경으로 유지합니다. 이번 Ruins Enhanced의 Separated Planet은 플레이 가능한 맵입니다. 배경 배치와 화면 크기별 LOD는 SKY_PLANET.md에 설명합니다.
