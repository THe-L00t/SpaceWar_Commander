기호 이미지 사용법

체력: hp-base.png의 sourceRectLTRB [335, 304, 449, 414]
방탄판: armor-base.png의 sourceRectLTRB [375, 300, 489, 418]

이 두 PNG는 기존 편집기에서 사용하는 스프라이트 원본을 그대로 복사한 것입니다.
원본 안에는 이전 글자·게이지 영역도 있으므로 PNG 전체를 UI로 표시하지 마세요.
sprite-regions.json에 지정된 기호 영역만 텍스처의 sourceRect / UV로 그리면 됩니다.
이미지를 변경하거나 재생성하지 않았으며 원본 픽셀을 유지했습니다.
폭·높이 형식과 UV 형식도 JSON에 함께 적었습니다. 종횡비를 유지해 표시하세요.

R 키, 숫자, 나침반 눈금, 체력/방탄판/재장전 게이지는 이 이미지에서 가져오지 않습니다.
게임 렌더러에서 글꼴과 선·사각형으로 직접 그립니다.
