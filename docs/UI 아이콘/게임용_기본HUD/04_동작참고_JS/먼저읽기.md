# 동작 참고 코드

`hud-motion.reference.js`는 현재 웹 편집기의 나침반 계산·재장전 시뮬레이션 원본이다. 브라우저 전역 `window.SW_HUD_MOTION`을 사용한다. C++/DirectX/Unity/Unreal에 그대로 실행하는 코드는 아니다.

게임 구현은 `03_동적_UI_구현명세/02_동적_상태와_계산식.md`를 기준으로 한다. 이 코드의 startReload / fire / advance는 미리보기용 무기 시뮬레이터이므로 실제 무기 로직이 이미 있다면 중복 실행하지 않는다. compassTicks·weaponState 계산을 참고할 수 있다.

이전 편집기 코드와 새 게임용 상태 예시의 필드 대응:

| 참고 JS 필드 | 게임용 예시 필드 |
|---|---|
| state.compass.yaw | view.yawDegrees |
| state.compass.centerX / width / pixelsPerDegree | theme.compass의 동명 필드 |
| state.compass.autoRotate | 게임에서는 false. 실제 방향 전달 |
| state.hud.ammo / reserve / reloadKey | weapon의 동명 필드 |
| state.hud.showReload | UI 표시 여부. 예시에서는 true |
| state.weapon.magazineSize | weapon.magazineSize |
| state.weapon.reloadDuration | weapon.reloadDurationSeconds |
| state.weapon.lowAmmoPercent | theme.reload.lowAmmoPercent |
| runtime.reload !== null | weapon.isReloading |
| runtime.reload.elapsed / duration | weapon.reloadElapsedSeconds / reloadDurationSeconds |
| runtime.time | timeSeconds |

새 `hud-theme.json`과 `runtime-state.example.json`은 별도의 게임용 명세 구조다. 이 JS에 직접 넘길 때에는 위 필드로 변환해야 한다. 기존 편집기의 JSON 불러오기 기능에도 이 명세를 직접 넣지 않는다.
