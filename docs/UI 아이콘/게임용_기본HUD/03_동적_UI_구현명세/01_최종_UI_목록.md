# 최종 사용할 UI

| 묶음 | PNG로 읽는 것 | TTF로 그리는 것 | 도형으로 그리는 것 | 연결할 게임 데이터 |
|---|---|---|---|---|
| 체력 | 십자 기호 | 체력, 현재 수치 | 빈 트랙, 체력 채움 | currentHP, maxHP |
| 방탄판 | 방패 기호 | 방탄판, 현재 수치 | 빈 트랙, 방탄판 채움 | currentArmor, maxArmor |
| 나침반 | 없음 | N/NE/E/SE/S/SW/W/NW, 방위 숫자, 현재 각도 | 이동 눈금, 기준선, 고정 중앙 표시 | 카메라/캐릭터의 수평 회전각 |
| 재장전 | 없음 | 장전 키, 재장전, 재장전 중, 퍼센트, 부족 문구 | 키캡 테두리, 진행률 트랙·채움 | ammo, reserve, capacity, isReloading, elapsed, duration, 입력 설정 |
| 공통 글꼴 | 없음 | Pretendard / Rajdhani | 해당 없음 | 글자 내용, 크기, 색, 굵기 |

재장전 판단에 현재 장탄수·예비 탄약·탄창 용량이 필요하다. `08 / 096` 장탄수 표시는 선택적으로 같은 글꼴로 그릴 수 있다. 별도의 장탄수 PNG나 총기 기호는 필요하지 않다.

## 이번에 가져갈 파일

- 기본 글꼴: `01_글꼴_TTF/Pretendard-Regular.ttf`, `Rajdhani-Regular.ttf`.
- 강조용 글꼴: 같은 폴더의 `Pretendard-Medium.ttf`, `Rajdhani-Medium.ttf`. Regular만으로도 구현 가능하며 강조가 필요할 때 추가한다.
- 기호 텍스처: `02_기호_이미지/hp-base.png`, `armor-base.png`.
- 기호 영역: 같은 폴더의 `sprite-regions.json`. LTRB, XYWH, UV 세 형식을 제공한다.
- 외형 설정: `hud-theme.json`. 원본 편집기의 위치·색·크기를 기준으로 했다.
- 동적 값 예시: `runtime-state.example.json`. 예시 수치를 고정하지 말고 실제 게임 값으로 갱신한다.
- 글꼴 라이선스·출처: `99_라이선스_출처`.

숫자·한글을 통째로 이미지에 저장하거나 체력 0~100, 장전 진행률 0~100 이미지를 만들지 않는다. 폰트 크기와 게이지 비율을 변경해 표시한다.

## 글꼴 지정

Pretendard Regular(400): 체력, 방탄판, 재장전, 재장전 중, 탄약 없음 등 한글.
Rajdhani Regular(400): 82, 64, 08/096, R, 50%, N·NE·E 등 숫자·영문·방위.
Medium(500): 필요한 강조 문구에 사용. Rajdhani에는 한글이 없으므로 한글은 Pretendard로 지정한다.
TTF를 게임 패키지에서 읽으며 사용자 PC에 글꼴을 미리 설치하는 방식에 의존하지 않는다.
