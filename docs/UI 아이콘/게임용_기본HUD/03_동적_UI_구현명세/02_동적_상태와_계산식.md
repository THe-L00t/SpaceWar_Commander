# 게임 값과 그리기 규칙

외형: `hud-theme.json`. 런타임 값: `runtime-state.example.json`의 구조를 참고한다. 파일 경로는 해당 JSON이 들어 있는 폴더 기준이다. 숫자는 1920×1080 기준 px, 각도는 도, 시간은 초다.

## 체력·방탄판

ratio = maximum > 0 ? clamp(current / maximum, 0, 1) : 0
fillWidth = theme.barWidth * ratio

빈 트랙은 항상 전체 폭으로, 채움은 계산한 폭으로 그린다. 체력은 foreground, 방탄판은 armor 색을 쓴다. 숫자는 clamp한 현재 값을 TTF로 표시한다. 체력 0이면 채움 폭만 0이 된다. 방탄판도 같은 계산을 사용한다.

## 나침반

normalize360(a) = ((a % 360) + 360) % 360
delta = normalize360(tickAngle - yawDegrees + 180) - 180
tickX = centerX + delta * pixelsPerDegree

5°마다 눈금, 15°마다 숫자, 45°마다 방위(N/NE/E/SE/S/SW/W/NW)를 표시한다. 중앙 표시와 현재 각도는 고정된 위치에 그린다. 눈금·방위는 clipRect 안에서만 그려 영역 밖을 자른다. 현재 각도는 round(yawDegrees) % 360으로 표시한다. 북쪽은 0°, 동쪽은 90°다. 엔진의 기준축·회전 부호가 다르면 yaw를 먼저 변환한다.

원래 편집기의 autoRotate는 테스트 기능이다. 게임에서는 실제 카메라/캐릭터의 방향을 매 프레임 받는다. 359°에서 0°로 넘어갈 때 일반 뺄셈을 쓰면 눈금이 튀므로 위 delta 공식을 사용한다.

## 재장전 표시: 상태 우선순위

게임 무기 로직이 제공하는 isReloading을 우선한다. 장전 중에는 진행률을 표시한다.

1. isReloading=true: `재장전 중`, 진행률 게이지, 퍼센트. 장전 키 안내는 숨김.
2. ammo=0, reserve=0: `탄약 없음`. 활성 장전 키 없음.
3. lowAmmo=true, reserve=0: `예비 탄약 없음`. 활성 장전 키 없음.
4. lowAmmo=true, canReload=true: `[R] 재장전`. 설정한 키를 표시하고 부드럽게 강조.
5. 나머지: 장전 안내와 진행률을 숨김. 장탄수 숫자는 선택적으로 유지.

capacity = max(1, magazineSize)
threshold = floor(capacity * clamp(lowAmmoPercent, 0, 100) / 100)
lowAmmo = ammo < capacity AND ammo <= threshold
canReload = NOT isReloading AND ammo < capacity AND reserve > 0

기본값은 탄창 30발, 부족 기준 30%로 9발 이하에서 안내가 켜진다. 0% 설정은 빈 탄창에서만 안내한다. 안내가 숨겨져도 부분 탄창의 장전 입력은 무기 로직에서 허용할 수 있다.

progress = duration > 0 ? clamp(elapsed / duration, 0, 1) : 1
fillWidth = progressWidth * progress
percent = floor(progress * 100 + 0.0000001)
promptAlpha = 0.72 + 0.28 * (0.5 + 0.5 * cos(timeSeconds * 2 * PI * pulseFrequency))

장전 입력은 실제 게임의 입력 매핑에서 받고, 키캡에도 동일한 매핑 값을 표시한다. `R`을 그림으로 고정하지 않는다. 게임을 일시정지하면 elapsed와 애니메이션용 time도 같은 게임 시간 기준으로 멈춘다.

UI는 ammo를 변경하지 않는다. 실제 재장전 완료 시 게임 무기 로직이 아래 값을 한 번만 적용하고 UI가 새 값을 표시한다.

transfer = min(max(0, capacity - ammo), max(0, reserve))
ammo += transfer
reserve -= transfer

예: 8/96에서 30발 탄창 재장전 완료 → 30/74. 예비 탄약 3발이면 8/3 → 11/0. 중간에 취소하면 원래 탄약 수치를 유지한다.

## 표시 순서와 해상도

텍스처 기호 → 빈 트랙 → 채움 → 글자/숫자 → 장전 안내 또는 진행률을 그린다. 동일 해상도 좌표로 UI를 구성한 뒤 uniform scale = min(width/1920, height/1080)을 적용하고 남은 여백은 양쪽에 균등 배치한다. 글꼴 크기·선 굵기·클리핑 영역에도 같은 배율을 적용한다. 이후 엔진의 안전 영역 정책에 맞춰 앵커를 조절한다.

## 확인할 동작

- 체력/방탄판 0, 최대값, 중간값, 최대값 0에서도 채움이 영역 밖으로 나가지 않는다.
- 나침반 359→0, 0→359와 동서남북 중앙 정렬을 확인한다.
- 탄약 10→9에서 안내가 켜지고, 예비 탄약 0이면 활성 키가 숨겨진다.
- 재장전 0%→50%→완료, 중간 취소, 예비 탄약 부족을 확인한다.
- 입력키를 변경하면 실제 조작키와 표시키가 같아야 한다.
