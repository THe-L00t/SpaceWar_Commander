# 이번 패키지의 글꼴 출처

TTF 파일 위치: `../01_글꼴_TTF/`.
Pretendard Regular/Medium: 한글·문구. 원본 출처 https://github.com/orioncactus/pretendard (v1.3.9).
Rajdhani Regular/Medium: 숫자·영문·방위. 원본 출처 https://github.com/google/fonts/tree/main/ofl/rajdhani . 한글은 포함하지 않는다.

현재 편집기의 정적 TTF 파일을 수정 없이 복사했다. 현재 시안에 사용한 대체 조합이며 참고 게임 전용 글꼴을 식별한 것은 아니다.
원본 다운로드 주소와 파일 SHA-256은 `sources.json`에 있다. 배포된 글꼴 라이선스 원문 `Pretendard-OFL.txt`, `Rajdhani-OFL.txt`를 글꼴과 함께 보관한다.
