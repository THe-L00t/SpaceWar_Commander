게임 UI 적용 안내

구현 범위: 체력, 방탄판, 나침반, 재장전 UI.
먼저 00_게임용_UI_안내.html을 열면 최종 구성을 볼 수 있습니다.

1. 사용할 파일

[글꼴] 01_글꼴_TTF
- Pretendard-Regular.ttf: 한글 문구(체력, 방탄판, 재장전 등).
- Rajdhani-Regular.ttf: 숫자, 방위(N/NE/E 등), 장전 키(R), 퍼센트.
- Medium.ttf 2개: 강조가 필요할 때 선택적으로 사용.
- 게임 리소스로 로드하고 99_라이선스_출처도 함께 보관해주세요.

[기호] 02_기호_이미지
- hp-base.png: 체력 십자 기호.
- armor-base.png: 방탄판 방패 기호.
- sprite-regions.json: 각 기호의 sourceRect/UV 좌표.
  PNG 전체에는 이전 글자·게이지도 있으므로 지정된 기호 영역만 그려주세요.

[배치·색·크기] 03_동적_UI_구현명세/hud-theme.json
- 1920×1080 기준 위치, 글꼴, 색상, 선 굵기, 게이지 폭 등이 들어 있습니다.
- 값을 엔진 UI 설정에 옮기거나 JSON을 읽는 코드를 구현해서 사용해주세요.

[게임 값 예시] 03_동적_UI_구현명세/runtime-state.example.json
- 현재/최대 체력, 현재/최대 방탄판, 방향각, 탄약, 재장전 상태 구조의 예시입니다.
- 예시 수치를 고정하지 말고 실제 게임 데이터를 연결해주세요.

2. 게임에 적용하는 순서

① TTF와 기호 PNG를 게임 리소스로 로드합니다.
② 테마 설정을 참고해 엔진의 텍스트·선·사각형·텍스처 UI로 배치합니다.
③ 아래 값을 연결해 UI를 갱신합니다.

- 체력/방탄판: 현재 수치는 텍스트로, 게이지 폭은 현재값÷최대값 비율로 표시.
  최대값이 0 이하이면 채움은 0, 비율은 0~1 범위로 제한합니다.
- 나침반: 카메라/캐릭터의 수평 회전각에 따라 방위와 눈금을 좌우 이동.
  중앙 표시는 고정하며 359°↔0° 전환이 끊기지 않게 계산합니다.
- 재장전 안내: 기본 30발 탄창에서 9발 이하이고 예비 탄약이 있으면 [R] 재장전 표시.
  표시 키는 실제 게임 입력 설정과 연결합니다.
- 재장전 중: 안내 대신 진행률 게이지와 퍼센트 표시.
  진행률은 경과 시간÷전체 장전 시간이며, 탄약 변경은 게임 무기 로직에서 처리합니다.
  예비 탄약이 없으면 활성 장전 키 대신 부족 문구를 표시합니다.

3. 참고

- 글자·숫자·키캡·게이지·나침반 눈금은 이미지로 고정하지 않고 동적으로 그립니다.

- JSON도 자동 적용 파일이 아니므로 엔진에서 읽거나 설정값을 옮기는 작업이 필요합니다.
