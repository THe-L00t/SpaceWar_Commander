# 실제 게임용 기본 HUD

팀원에게 전달할 짧은 설명: [00_팀원_전달용.txt](00_팀원_전달용.txt).

이번 구현 범위: 체력 · 방탄판 · 나침반 · 재장전. 글꼴은 이 네 UI의 공통 리소스다.

| 폴더 | 최종 사용 항목 | 게임에서의 용도 |
|---|---|---|
| 01_글꼴_TTF | TTF 4개 / 글꼴 2종 | 한글 Pretendard, 숫자·방위 Rajdhani. Regular 기본, Medium 강조 |
| 02_기호_이미지 | PNG 원본 2개 + 기호 영역 JSON | 체력 십자, 방탄판 방패를 지정된 영역만 표시 |
| 03_동적_UI_구현명세 | UI 목록·계산식·테마·상태 예시 | 게임의 값과 렌더러를 연결할 명세 |
| 04_동작참고_JS | 나침반·재장전 계산 코드와 대응표 | 동작 참고용 JavaScript. 엔진 전용 구현은 별도 |
| 99_라이선스_출처 | 글꼴 라이선스·출처·파일 확인값 | TTF와 함께 보관 |

**처음 확인:** `00_게임용_UI_안내.html`을 열면 글꼴, 기호 영역, 최종 UI 구성을 볼 수 있다.

실제 게임에 넣을 리소스는 TTF와 기호 텍스처다. 테마 JSON의 값은 게임 설정에 옮기거나 JSON 로더를 만들어 읽는다. 이 폴더의 JSON은 자동으로 게임에 적용되는 파일이나 기존 편집기 설정 파일이 아니다.

체력 숫자·게이지, 방탄판 숫자·게이지, 나침반 방위·눈금, R 키캡·장전 안내·진행률은 모두 텍스트와 도형으로 매 프레임 그린다. 상태별 UI 통이미지와 PNG 미리보기는 이 패키지에 넣지 않았다.

기호 텍스처는 기존 PNG 원본 그대로다. 원본에 문구·게이지가 함께 있으므로 `02_기호_이미지/sprite-regions.json`의 sourceRect/UV를 사용해 기호 부분만 그린다. 전체 PNG를 표시하면 안 된다.

편집기는 웹 Canvas용이다. 이 패키지도 특정 게임 엔진용 프리팹·위젯·DirectX 빌드가 아니다. 아래 명세를 해당 엔진의 텍스트·텍스처·사각형·선 그리기 기능으로 구현한다. 실제 탄약 이동·장전 완료 판정은 게임 무기 로직이 담당한다.

데미지, 직업·분대, 목표·함선 표시, 스킬·성장, 특성창은 이번 게임용 기본 HUD 패키지 범위에 포함하지 않았다. 기존 자료는 원래 위치에 보관되어 있다.
